[학생부 기록 정리 웹앱 사용방법]

1. 이 폴더의 "웹앱_실행.bat"를 더블클릭합니다.
2. 처음 한 번은 필요한 프로그램 설치로 1~3분 정도 걸릴 수 있습니다.
3. 브라우저가 열리면 학교생활기록부 조회 .xlsx 파일을 선택합니다.
4. "정리된 엑셀 만들기"를 누릅니다.
5. 변환이 끝나면 정리된 엑셀 파일이 다운로드됩니다.

종료 방법
- 실행 중인 검은색 창에서 Ctrl+C를 누르거나 창을 닫습니다.

처리 결과
- 과목 / 학년 / 학기 / 번호 / 성명 / 세부능력 및 특기사항
- 반복되는 제목, 머리글, 쪽번호, 학교명, 안내 행 제거
- 생략된 과목·학년·학기 자동 복원
- 페이지 경계에서 잘린 동일 학생 기록 연결

개인정보 안내
- 배치 파일로 실행하면 127.0.0.1(사용자의 PC)에서 처리됩니다.
- 공개 웹사이트에서는 파일이 변환을 위해 Vercel 서버로 전송됩니다.
- 애플리케이션은 업로드 파일과 변환 파일을 영구 저장하지 않습니다.
- 학생 개인정보 처리에 관한 학교·기관의 내부 지침을 확인한 후 이용해 주세요.

필요 환경
- Windows 10/11
- Python 3.10 이상 권장
- 첫 실행 시 패키지 설치를 위한 인터넷 연결

실행이 되지 않을 때
- ZIP 파일 안에서 바로 실행하지 말고, 반드시 먼저 압축을 모두 풀어 주세요.
- Windows가 경고하면 "추가 정보" → "실행"을 선택하세요.
- Python 설치 화면에서 "Add python.exe to PATH"를 선택했는지 확인해 주세요.
